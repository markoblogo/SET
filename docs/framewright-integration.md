# Framewright handoff (optional)

[Framewright](https://github.com/markoblogo/framewright) owns video workflow
selection, production recipes and experiment evidence. SET remains the planning
and orchestration layer. This document does not register a new preset or runtime.

For a requested video, a reviewable plan may contain:

| Stage | Output | Boundary |
| --- | --- | --- |
| Brief and source review | Audience, language, format, source facts, authorised assets | No invented product claims |
| Method selection | Framewright recipe and tested limits | Respect explicit tool preference |
| Storyboard and voice | Approved beats and measured speech timings | Paid voices/accounts need authorisation |
| Production | Project-specific render and mix commands | Consult selected tool docs; no inferred auto-install |
| Review | Final encoded-file QA and human review status | Failed sound QA is not a passed export |
| Delivery | Export, requested thumbnail/subtitles/copy, experiment record | Delivery is not upload approval |

The reusable router and catalogue stay in Framewright; do not copy them into SET.
No end-to-end SET-to-video execution integration is claimed by this documentation.
The future experiment log must record concrete tool versions and actual commands.
