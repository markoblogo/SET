# SET v0.5.0

SET 0.5.0 refreshes the supported toolchain and makes its public product surface easier to trust and reuse.

- Supports agentsgen 0.5.1 in the composite action and PR guard.
- Generates reviewable workflows pinned to `markoblogo/SET@v0.5.0`.
- Adds a CLI version command and richer PyPI metadata.
- Keeps the `web-ui` pilot diagrams on the default branch.
- Updates CI and release actions while limiting default workflow permissions.

The product boundary is unchanged: SET prepares and validates proposals. It does not run autonomous agents or apply repository changes.
